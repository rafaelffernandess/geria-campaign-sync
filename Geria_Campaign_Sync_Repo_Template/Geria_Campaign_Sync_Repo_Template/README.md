# Geria Campaign Sync — Player Feed

Este repositório deve conter **somente informações que o personagem já descobriu**.
Nunca coloque aqui o banco do GM, spoilers, eventos futuros ou chaves/tokens.

## Arquivo usado pelo Codex

`feed.json`

Depois de publicar este repositório, use a URL RAW de `feed.json` em:

**Geria Codex → Campaign Sync → URL do feed**

O Codex consulta o JSON automaticamente e aplica apenas eventos com `seq` maior do que o cursor local.

## Uso pelo GM

O GM pode atualizar `feed.json` conforme a campanha avança. O jogador não precisa baixar patches para descobertas comuns.

Patches locais ficam reservados a alterações de aplicativo, correções, migrações ou grandes mudanças estruturais.
